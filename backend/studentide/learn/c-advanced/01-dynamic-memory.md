---
title: Memory you ask for
summary: malloc, free and arrays whose size you only know at run time.
---
So far every array had a size fixed when you wrote the program. With `malloc` you ask for memory **while the program runs**, as much as you need. It lives on the *heap* until you give it back with `free`.

```c
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    int n = 6;
    int *a = malloc(n * sizeof(int));   /* room for n ints */
    if (a == NULL) {                     /* malloc can fail */
        printf("out of memory\n");
        return 1;
    }
    for (int i = 0; i < n; i++) {
        a[i] = i * i;                    /* use it like an array */
    }
    for (int i = 0; i < n; i++) {
        printf("%d ", a[i]);
    }
    printf("\n");
    free(a);                             /* give it back */
    return 0;
}
```

- `sizeof(int)` is how many bytes one `int` takes, so `n * sizeof(int)` is the right size for `n` of them.
- `malloc` returns `NULL` if it can't find the memory. Always check.
- `calloc(n, sizeof(int))` does the same but fills the memory with zeros.
- `realloc(a, m * sizeof(int))` grows (or shrinks) a block, keeping what was in it. It may move the block, so always use the pointer it returns.
- Every `malloc` needs exactly one `free`. Forgetting is a **memory leak**; using memory after `free` (a *dangling pointer*) or freeing twice is a bug that may crash much later.

Things to try:

1. Read `n` from the input instead of fixing it at 6.
2. Grow the array with `realloc` to `2 * n` and fill the new half.
3. Print `a[0]` after `free(a)`. It might still "work", which is exactly what makes this bug dangerous.

## Exercise

The input is a count `n` (you only know it when the program runs, so allocate the array with malloc) followed by `n` whole numbers. Allocate exactly enough memory, read the numbers, then print how many are above their average. Free the memory before you finish.

```input
5
4 8 15 16 23
```

```c starter
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    int n;
    scanf("%d", &n);
    /* allocate n ints, read them, count the ones above the average */
    return 0;
}
```

```c solution
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    int n;
    scanf("%d", &n);
    long *a = malloc(n * sizeof(long));
    if (a == NULL) {
        return 1;
    }
    long long sum = 0;
    for (int i = 0; i < n; i++) {
        scanf("%ld", &a[i]);
        sum += a[i];
    }
    int above = 0;
    for (int i = 0; i < n; i++) {
        if ((long long)a[i] * n > sum) {
            above++;
        }
    }
    printf("%d\n", above);
    free(a);
    return 0;
}
```
