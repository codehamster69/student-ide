---
title: Decisions
summary: if, elif, else, and the importance of indentation.
---
Python groups code by **indentation**: the lines indented under an `if` belong to it. `elif` ("else if") tests another condition, and `else` catches everything left.

```python
t = int(input())

if t >= 35:
    print("hot")
elif t >= 20:
    print("pleasant")
else:
    print("cold")
print("done")   # not indented: always runs
```

Combine conditions with `and`, `or` and `not`. Python also lets you chain comparisons: `if 13 <= age <= 19:`.

## Exercise

Read a whole number and print `Fizz` if it is divisible by 3, `Buzz` if divisible by 5, `FizzBuzz` if divisible by both, and the number itself otherwise.

```input
15
```

```python starter
n = int(input())
```

```python solution
n = int(input())
if n % 15 == 0:
    print("FizzBuzz")
elif n % 3 == 0:
    print("Fizz")
elif n % 5 == 0:
    print("Buzz")
else:
    print(n)
```
