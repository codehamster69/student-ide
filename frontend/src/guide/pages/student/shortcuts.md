On a Mac use `⌘` where this page says `Ctrl`.

## Editor

| Action | Keys |
| --- | --- |
| Run program | `Ctrl + Enter` |
| Indent | `Tab` |
| Find | `Ctrl + F` |
| Undo | `Ctrl + Z` |

The same list is shown at the bottom of the question panel.

## Sandbox Labs

| Action | Keys |
| --- | --- |
| Run the assignment | `Ctrl + Enter` |
| Switch to assignment 1 to 9 | `Ctrl + 1` … `Ctrl + 9` |

## Vim keys

Turn on the **Vim** switch beside the editor's **Reset** button (and in each Sandbox Lab file editor) to use Vim key bindings. Press `Esc` for normal mode and `i` to type. The setting is remembered in your browser or app. Keys typed in Vim are recorded like any other typing.
