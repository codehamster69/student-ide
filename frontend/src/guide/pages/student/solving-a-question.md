## The screen

- **Left panel: the question.** The prompt, any examples, and a sample input if the teacher added one. The arrow button in the top bar hides or shows it. In a lab it also lists every question in the lab, with Previous and Next.
- **Middle: the editor.** Your code, with syntax colours. The file name and language are shown above it.
- **Bottom: Input and Output.** Type input for your program in the input box, then see its output below. Drag the edges of the panes to resize them; double-click an edge to reset it.
- **Top bar.** The recording pill, **Run**, **Check** (when the question has tests) and **Finish lab** or **Finish**.

## Run

**Run** compiles (if needed) and runs your program with the text in the input box. Shortcut: `Ctrl + Enter` (`⌘ + Enter` on a Mac). Run as often as you like; each run is recorded with its output.

## Check

When the teacher added tests, **Check** runs them on your code and shows which pass. Some tests are *hidden*: you see only pass or fail for them, never their input or expected output.

In a normal lab Check is just for you and is never a grade. (Competitions are different: see [Competitions](competitions).)

## Reset

**Reset** puts the starter code back for the question you are on. A confirmation appears first, and `Ctrl + Z` brings your own code back if you change your mind. Reset is not counted as typing.

## Language

Some labs let you answer in more than one language. Use the **Language** switch above the editor. Each language keeps its own code, so you can switch back.

## Labs are one sitting

A lab opens as one **sitting**: every question is a tab, and each keeps its own code, input, output and test results while you move between them. Moving to another question is fine and is never counted as looking away.

When you are done, press **Finish lab**. The dialog tells you how many questions you wrote code for.

## Coming back later

Everything is saved as you work. While the lab is open you can press **Continue lab** on the home page and carry on: each question opens with the code you left in it. Questions you never touched stay empty. If the lab is closed by your teacher, it is hidden and you cannot start new sittings.

Single practice tasks use **Finish** instead of **Finish lab**. After finishing a practice session you cannot edit it.
