## Sign in

Use your college Google account (the one ending in `@iiitsurat.ac.in`). Your roll number is the part before the `@`, written in capitals, so `pg25cs07@iiitsurat.ac.in` becomes **PG25CS07**. Your teacher uses that same roll number when they add you to a lab.

Only college accounts can sign in. If you see a message about your account, check that you picked the college address and not a personal one.

## The consent screen

The first time you sign in you see **Before you start**. It lists what the editor records, what it does not record, and who can see it. Read it, tick the box and press **Start**. Nothing is recorded before you agree.

If the text changes later (for example when a new feature is added), you are asked to read it again before your next session. The page [What we record](what-we-record) explains the same things in more detail, but the consent screen is the text you agree to.

The first time you open a Sandbox Lab in the desktop app you see a short extra consent for the terminal. See [Sandbox Labs](sandbox-labs).

## The home page

Your home page shows, from top to bottom:

- **Your labs.** Labs your teacher has opened for you. Each card shows how many questions you have finished. **Start lab** opens the editor; it becomes **Continue lab** once you have begun.
- **Competitions.** A gold card appears when a class competition is open for you. See [Competitions](competitions).
- **Sandbox labs.** Labs that run in the desktop app, grouped by subject.
- **Learning lab.** An always-open place to learn C, C++ and Python with short lessons. See [Learning lab](learning-lab).
- **Practice.** A few open practice tasks you can try any time.

If you have attendance set up, you also see **My attendance** in the header. See [Attendance](attendance).
