A **lab** is one sitting (a weekly lab class, an assignment, or a staged study session) made of ordered **questions**. Open **Labs** in the teacher area.

## Build it

1. **New lab.** Give it a title and instructions for students, plus a subject and a programming language (Python, C, C++, Java or JavaScript). The language sets the editor mode, file name, Run and Check.
2. **Add questions.** Each has a title, a prompt, optional starter code that opens in the editor (Tab indents), and an optional sample input that prefills the input box. Reorder with the arrows. You can edit, reorder or remove a question only while nobody has recorded on it; after that, edit it but don't delete.
3. **Tests (optional).** Add stdin/stdout tests to a question to give students a **Check** button. Mark a test *hidden* so students see only pass or fail. In labs tests are a self-check and never a grade.
4. **Assigned to.** Paste roll numbers (commas, spaces or new lines), click students who have already signed in, or tick *Everyone who signs in*. You can assign roll numbers before those students ever log in. Full college addresses work too and become the same upper-case id.
5. **Status.**
   - **Draft**: only you see it.
   - **Open**: assigned students see it and can start. Needs at least one question.
   - **Closed**: hidden from students; recordings are kept.

A lab with recordings cannot be deleted, only closed.

## While it runs

**Progress** on the lab page shows, per student and question, who started and who finished. **Watch live** opens the class view ([Live view](live-view)). Afterwards, find sessions under **Review** ([Review timeline](review-timeline)).

If class groups are attached, **Open** asks which group is performing; see [Attendance](attendance).

## Who sees a lab

Each lab records its owner. With Google sign-in you see and manage only labs you own or were added to as a co-teacher, and only the sessions, timelines, live views and boards of those labs. A direct link to someone else's lab answers "not yours" without signing you out.

- The owner (or an admin) shares a lab with co-teachers by college address from the **Teachers** panel. Co-teachers can do everything the owner can except change the sharing. Student addresses are refused.
- Only admins change the owner. Labs made before ownership existed have no owner and are visible to admins only until handed over.
- Admins see every lab.

## Changing a lab students already have

Editing a question changes what *new* sessions see, never what an old recording was answering. Each session keeps a copy of the question as the student saw it.
